# Odin workspace

This folder holds my Odin tasks. The tools, rules and full workflow are in the odin-kit repo
at `{kit}`: read `{kit}/CLAUDE.md` and `{kit}/docs/` before doing anything here.

- `tasks/<task id>/`: one folder per approved task (made with `odin-task new <task id>`).
- `IDEAS.md`: every idea I've drafted or submitted, and which task id each became.
- `NOTES.md`: my own pace calibration and the feedback from my reviews.
